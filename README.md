# 📖 Berbagi Cerita App

A modern Single Page Application (SPA) for sharing stories with photos and location maps.  
Built using JavaScript, Webpack, MVP Architecture, Google Maps API, and Story API from Dicoding.

## Features

- User Authentication (Login/Register)
- Display Stories from API
- Interactive Digital Map with Markers
- Select Location by Clicking Map
- Capture Photo Directly from Camera
- Upload Image from Device
- SPA Navigation with Hash Routing
- Smooth View Transition Animation
- Responsive Design
- Accessibility Support (Skip to Content, Semantic HTML, Labels)

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Webpack
- Leaflet.js
- Google Maps API
- Dicoding Story API
- MVP Architecture

## Architecture

This project implements the **MVP (Model-View-Presenter)** architecture pattern:

- **Model** → Handle API & data
- **View** → Handle UI rendering
- **Presenter** → Connect Model and View
